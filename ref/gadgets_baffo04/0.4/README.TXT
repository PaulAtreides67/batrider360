HOW TO USE:
Drop this zip file in the mame/artwork directory.
(for example, if you installed mame in C:\mame, place the file at C:\mame\artwork\batriderj.zip).
Enable the Layout helper plugin in mame under "Configure Options" > "Plugins".
Start playing with the batriderj.zip romset as usual.
