はじめに

3つのファイルを本体にコピーし、ゲームを起動して、START を押しましょう。

ARMED POLICE BATRIDER（アームドポリス バトライダー）は、RAIZING（ライジング）が 1998 年に発売したアーケード用シューティングゲームです。CHASE! は、COIN-OP GAME STUDIO が作った、このゲームの新しいモードです。つなげて伸ばすチェーン、自機に飛んでくる勲章、そして難しくなりすぎないランクが加わります。この Xbox 360版（バージョン 0.21）には、CHASE! とオリジナルのアーケードゲームの両方が入っています。さらに、トレーニングモード、ステートセーブ、リプレイ、そしてゲーム画面の横に並ぶ情報パネル（「ガジェット」）があります。

用意するもの

  • Aurora などのダッシュボードから自作の .xex ファイルを起動できる Xbox 360 本体。
  • MAME 用 ROM セット batrider.zip（日本版 batriderj を含むマージ形式）。ご自身で用意してください。CHASE! は、ゲームを起動するたびにこのファイルから作られます。
  • コントローラ1台。このゲームは1人用で、最初に接続されているコントローラを使います。

batrider360.xex、batrider360_manual.bin、batrider.zip を、本体のハードディスクか USB ドライブの同じフォルダにコピーします。それから、ダッシュボードで batrider360.xex を起動します。

ゲームを起動する

最初に、ROM セットを読み込む間 NOW LOADING と表示されます。初めて起動したときは、メニューの効果音も作り、batrider360_menusnd.bin としてセーブします。そのあと、アーケードゲームの WARNING 画面、COIN-OP GAME STUDIO のロゴ、ゲームのオープニングと続きます。START を押すと、いつでもすぐにタイトル画面へ進めます。画面が暗い赤のままのときは、ROM セットが見つかっていません（ページ）。

縦画面のゲームと、テレビの向き

BATRIDER は縦画面のゲームです。元のアーケード筐体と同じく、画面は横幅より縦のほうが長くなっています。OPTIONS > GENERAL SCREEN の ROTATION（ページ）で、テレビをどう置いているかをゲームに知らせます。

ROTATIONテレビの置きかた表示
OFFふつう（横長）の向きゲームが画面の中央に表示され、左右にガジェット（ページ）が並びます。これが初期設定です。
LEFT縦置き。テレビの上端が左にくるゲームが画面いっぱいに表示され、上下の帯にガジェットが並びます。
RIGHT縦置き。テレビの上端が右にくるLEFT と同じで、向きが逆になります。
注意

すべてのテレビが、縦置きできるように作られているわけではありません。縦置きに対応したテレビやスタンドだけを回してください。通気口は絶対にふさがないでください。また、電源を入れたまま回さないでください。

ランク

ゲームは、プレイヤーの調子をランクという隠れた難しさで記録しています。ショットを撃つ、アイテムを取る、撃墜されずにいるとランクが上がり、ランクが高いほどゲームは難しくなります。撃墜されると、ランクは下がります。オリジナルゲームでは、ランクに上限はありません。開始時のランクは、アーケードがそのコースに設定している値です（待機させたあとの値）：ADVANCE 14.9020%、TRAINING と NORMAL 2.7451%、SPECIAL 20.9804%。ガジェットの RANK BAR にも同じ値が表示されます。ADVANCE SPECIAL は ADVANCE の値から始まります。CHASE! では、ランクは 50% から始まり、75% を超えることはありません。

ボス

各ステージの最後にはボスがいて、制限時間があります。CHASE! では残り時間を画面上に秒で表示します。時間切れになると、戦いは終わります。

当たり判定

赤い輪の中の白い点が、自機の当たり判定です。自機のなかで、弾に当たるのはこの部分だけです。それ以外の部分は、弾が重なってもかまいません。当たり判定は自機と同じ層に描かれるため、自機の上に描かれるものがあると、当たり判定も一緒に隠れます。

HITBOX の設定（TRAINING のページと、OPTIONS > DEBUG MENU にあります）で、両方のゲームでの表示を選べます。OFF、PLAYER（自機の当たり判定。初期設定）、ALL の3つです。

ALL にすると、ゲームが判定に使っている枠もすべて表示されます。

  • 赤：触れるとダメージを受ける敵
  • 青：地上の目標など、撃つことしかできない目標
  • マゼンタ：敵弾
  • そして PLAYER と同じ、自機の当たり判定
CHASE! モード

CHASE! のルール

CHASE! で変わることを、ここにまとめました。このあとのページで、1つずつくわしく説明します。

ランク

50% から始まり、最大で 75% までです。撃墜されると下がりますが、50% より下にはなりません。倍率が高いほど、速く上がります。

チェーン

敵を1体倒すごとに、チェーンが1増えます。16体倒すごとに倍率が1段階上がり、最大で x8 です。倒した敵の得点は、ふだんの得点に倍率を掛けた値になります。

タイマー

敵を倒すたびに、チェーンのタイマーが回復します。画面の上半分では 1.5秒まで、下半分では1秒までです。

タイマー切れ

x1 より上のとき：倍率が2段階下がります。x1 のとき：チェーンが切れます。

撃墜されたとき

倍率と勲章の得点が半分になり、タイマーは3秒間止まります。

ボム

ボムの発動中と、そのあと1秒間、タイマーが止まります。

勲章

自機の近くの勲章は、自機に引き寄せられます。SHOT を押している間は、すべての勲章が引き寄せられます。1,000点以上の勲章を落とすと、チェーンが切れます。

チェイスブレイク

x4 以上で SPECIAL を押すと、敵弾とザコ敵がすべて勲章に変わります。倍率は x1 に戻り、5秒間固定されます。

エクステンド

1,000,000点ごとに、撃墜された機体が1機復帰します。残機は最大5です。

敵の狙い

敵の近くを飛んでいると、敵の狙いが甘くなります。

ランクは 50% から 75% の間

CHASE! のプレイは、ランク 50% から始まります。そこからランクは、ふだんどおりに上がっていきます（時間とともに少しずつ上がり、ショット、アイテム、エクステンドでさらに上がります）。CHASE! ではそれに加えて、倍率が x1 より1段階上がるごとに、ランクがさらに上がりやすくなります。ただし 75% を超えることはないので、CHASE! がそれ以上難しくなることはありません。

撃墜されると、ランクは 50% に向かって下がりますが、50% より下にはなりません。コンティニューすると、ちょうど 50% に戻ります。

固定の設定

CHASE! はつねに、難易度 HARD、残機3でプレイします。オリジナルゲームのボーナス機体の代わりに、独自のエクステンドを使います。DIP スイッチの影響は受けず、TRAINING コースのオートボムもありません。CHASE! は1人用です。

CHASE! モード

チェーンと倍率

途切れずに敵を倒し続けましょう。チェーンは倒した数を数え、倍率は1体ごとの価値を決めます。

敵を1体倒すごとに、チェーンが1増えます。16体倒すごとに倍率が1段階上がり、x1 から x8 まで上がります。倒した敵の得点は、ふだんの得点に倍率を掛けた値になります。チェーンは x8 を超えても数え続けますが、倍率は x8 のままです。

タイマー

敵を倒すと、チェーンのタイマー（画面の左側のゲージ）も回復します。

自機の位置敵を倒したときのタイマー
前方：画面の上半分1.5秒（満タン）まで回復
後方：画面の下半分1秒まで回復

どちらにいるかは、左のバーの位置マークでわかります。前に出ると、チェーンを保ちやすくなります。後ろに下がっていると、次の敵を倒すまでの時間が0.5秒短くなります。

ヒント

ボスへの命中もチェーンに数えられ、ボスの攻撃の合間もタイマーを保ってくれます。ボス戦は、倍率を上げるのにちょうどよい場面です。

タイマーが切れると

x1 より上のときは、倍率が2段階下がり、タイマーは1秒になります。その1秒の間に何も倒せないと、さらに2段階下がります。

x1 のときは、チェーンが切れ、数は0に戻ります。

x8 でタイマーが満タンの状態から1体も倒さないと、4.5秒でチェーンが切れます。

そのほかチェーンに影響すること

撃墜されたとき倍率が半分になり（x8 は x4 に）、勲章の得点も半分になります。次の機体が来るまでの3秒間、タイマーは止まります。
ボムを使ったときボムの発動中と、そのあと1秒間、タイマーが止まります。ボムで倒した敵も、チェーンに数えられます。
勲章を落としたとき1,000点以上の勲章を画面の外へ落とすと、チェーンが切れます。
チェイスブレイク倍率を使い切り、x1 に戻ります（ページ）。
コンティニューチェーン、倍率、勲章の得点が、すべて最初からになります。
CHASE! モード

勲章とマグネット

勲章の得点のしくみは、オリジナルゲームと同じです。CHASE! では、勲章を自機に引き寄せるマグネットが加わります。

自機からおよそ100ピクセル（画面の幅の約5分の2）以内に入った勲章は、自機へまっすぐ引き寄せられます。

SHOT を押している間は、マグネットが画面全体に届き、すべての勲章が自機へ飛んできます。

ボムで建物から出てきた勲章など、地上にある勲章は、撃っていなくても、どこからでも引き寄せられます。

マグネットが働くのは、機体が飛んでいる間だけです。撃墜されてから次の機体が来るまでの間は、勲章はふつうに落ちていきます。

ヒント

マグネットのおかげで、勲章の得点を高く保つのがずっと楽になります。大切に守りましょう。1,000点以上の勲章を落とすと、勲章の得点が戻るだけでなく、チェーンも切れます。

CHASE! モード

チェイスブレイク

倍率と引き換えに、画面いっぱいの勲章を手に入れましょう。

倍率が x4 以上のときに SPECIAL（X）を押すと、チェイスブレイクが発動します。

  • 画面上の敵弾がすべて消え、ザコ敵がすべて破壊されます（それぞれ、ふだんの得点が入ります）。
  • そのひとつひとつが、いまの勲章の得点と同じ得点の勲章を残し、マグネットが自機へ引き寄せます。画面に出しきれない勲章は、同じ得点でスコアに直接加えられます。
  • 倍率は x1 に、チェーンは0に戻ります。

そのあと、倍率は5秒間固定されます。その間も敵を倒せば得点は入りますが、チェーンは増えません。左のゲージは白くなって減っていきます。倍率がもう一度 x4 になるまで、次のチェイスブレイクは使えません。

チェイスブレイクが発動すると、メッセージ行に CASH IN と表示されます。

ボスはザコ敵ではありません。ボスだけで敵弾もないときなど、勲章に変えられるものが何もないときは、SPECIAL を押しても何も起こらず、倍率はそのままです。

ヒント

チェイスブレイクで出た勲章は、おまけのボーナスです。画面の外へ落としても、勲章の得点は戻りません。

メモ

SPECIAL は、バトルガレッガのゲスト機体のオプションのフォーメーションも切り替えます。これらの機体では、短く押す（0.5秒以内に離す）と、離したときにフォーメーションが切り替わります。長く押す（0.5秒押し続ける）と、フォーメーションは変わらずにチェイスブレイクが発動します。

CHASE! モード

残機・エクステンド・コンティニュー

エクステンド

1,000,000点ごとにエクステンドし、メッセージ行に EXTEND と表示されます。

エクステンドすると、撃墜された機体が1機復帰し、チームの最後尾に加わります。撃墜された機体がいないときは、エクステンドはストックされ、次に機体が撃墜されたときにすぐ使われます。

残機は最大5です（飛べる機体と、ストック中のエクステンドの合計）。残機が5のときのエクステンドは、代わりに 100,000点になり、メッセージ行に MAX LIVES と表示されます。

チームのアイコンの横の数字が、残機です。残り1になると赤くなります。

コンティニュー

最後の機体が撃墜されると、CONTINUE? と表示され、カウントダウンが始まります。START を押すと、同じチームでプレイを続けられます。

コンティニューは無制限です。フリープレイなので、何回でも続けられます。コンティニューすると、チェーン、倍率、勲章の得点が最初からになり、ランクは 50% に戻ります。

コンティニューすると、スコアは無効になります。イニシャルを入力しないため、ランキングには登録されず、リプレイもセーブされません（ページ）。TRAINING にはコンティニューがなく、GAME OVER になると TRAINING のページに戻ります。

オリジナルゲーム

MODE を ORIGINAL か ADVANCE SPECIAL にすると、START RUN で ARMED POLICE BATRIDER をアーケードとまったく同じようにプレイできます。

CHASE! のルールは何も適用されません。チェーンも、勲章のマグネットも、チェイスブレイクもなく、ランクに上限もありません。アーケードの初期設定（難易度 NORMAL、残機3、1,500,000点ごとにエクステンドのアイテム）でプレイします。設定は DIP スイッチで変えられます（ページ）。フリープレイで、画面もアーケードとまったく同じです（CHASE タグはありません）。当たり判定とガジェットは、両方のゲームで使えます（ページ）。

プレイ以外のものは、すべて両方のゲームで共通です。メニュー、ポーズメニュー、TRAINING、ステートセーブ、リプレイです。CHASE! とオリジナルゲームは、それぞれ別のランキングを持ちます。ADVANCE SPECIAL のスコアは ORIGINAL のランキングに入ります（ページ）。

有利になるものを使うとスコアは無効になります。ほかの行動でも無効になるものがあります（隠しコマンド、CONTROLS、画面と音の設定は影響しません）。

無効なスコアは、ガジェット（ページ）の STAGES、SAVE REPLAY?（* が付くのは DIP スイッチを変えたプレイだけ）、REPLAY DATA（* が付きます）に赤く表示されます。

ステートセーブ

どの瞬間でもゲームをセーブして、好きなときにそこへ戻れます。

SAVE STATE（ポーズメニュー）と LOAD STATE（ポーズメニューとタイトルメニュー）を選ぶと、スロットのページが開きます。スロットは CHASE! と ORIGINAL の MODE ごとに10個です。それぞれのスロットに、セーブしたときのステージとスコアが表示され、選んでいるスロットにはそのときの画面の小さな写真が表示されます。

SAVE STATE

プレイ中に使えます。スロットを選んで A を押すと、セーブされます。使用中のスロットは、確認のあと上書きされます。

LOAD STATE

左右で、もう一方の MODE のスロットを見られます。A を押すと、確認のあとステートセーブを読み込みます。もう一方の MODE のステートセーブを読み込むと、ゲームもそちらに切り替わります。X でステートセーブを消去します（確認があります）。

読み込んだあと、ゲームはポーズメニューで待っています。RESUME を選ぶと続きます。ステートセーブを保存または読み込むと、スコアは無効になります。イニシャルを入力しないため、ランキングには登録されず、リプレイもセーブされません（ページ）。

メモ

ランキングは、ステートセーブに含まれません。古いステートセーブを読み込んでも、古いランキングが戻ることはありません。

ステートセーブは、.xex と同じ場所にファイルとしてセーブされます。CHASE! は batrider360_state_c01.bin～_c10.bin、ORIGINAL は _o01.bin～_o10.bin です。batrider360 のほかのバージョンでセーブしたステートセーブは、読み込めないことがあります。

リプレイ

プレイはすべて、最初から記録されています。よいプレイはセーブしておきましょう。

プレイが終わると SAVE REPLAY? と表示され、MODE、到達したステージ、スコア、プレイ時間が出ます。A でセーブし、B で捨てます。10秒に満たないプレイと、リプレイをセーブできないプレイ（ページ）では表示されません。リプレイは30個までセーブできます。30個すべて使っているときは、いちばん古いリプレイと置き換わります。

REPLAY DATA

タイトルメニューの REPLAY DATA を選ぶと、セーブしたリプレイが新しい順に、1ページに12個ずつ並びます。上には、使っているスロットの数が出ます。それぞれの行に、MODE（CHA か ORG）、到達したステージ、スコア、長さが表示されます。無効なスコアの行は赤く、* がつきます。A でリプレイを再生し、X で消去します（確認があります）。
