はじめに

3機のバトライダーで、1回のプレイ。ゲームを ROM セットと同じ場所に置き、画面の置きかたを知らせて、STARTボタンを押しましょう。

ARMED POLICE BATRIDER（アームドポリス バトライダー）は、RAIZING（ライジング）による 1998 年のアーケード用シューティングゲームです。CHASE! は COIN-OP GAME STUDIO によるアレンジモードで、オリジナルゲームと同じタイトル画面に並んでいます。つなげて伸ばすチェーン、自機に飛んでくる勲章、そして手の届く範囲にとどまるランクが特徴です。この取扱説明書は Xbox 360版 バージョン 0.14 のものです。両方のゲーム、トレーニング、ステートセーブとリプレイ、そして基板の中身を見せるガジェットを収めています。

用意するもの

  • Aurora などのダッシュボードから自作の .xex ファイルを起動できる Xbox 360 本体。
  • お手持ちの MAME 用 ROM セット batrider.zip（日本版基板 batriderj を含むマージ形式）。CHASE! は読み込むときにここから作られます。
  • コントローラ1台（1人用。最初に接続されているもの）。

batrider360.xex、batrider360_manual.bin、batrider.zip を、本体が書き込めるドライブ（ハードディスクか USB ドライブ）の同じフォルダに入れ、ダッシュボードから batrider360.xex を起動します。

電源を入れる

本体のロゴ、ROM セットを読み込む間の NOW LOADING（最初の1回だけ、メニューの効果音を作って batrider360_menusnd.bin にセーブします）、アーケード基板の WARNING 画面、COIN-OP GAME STUDIO のロゴ、オープニングの順に進み、START でタイトル画面へ。画面が暗い赤のままなら ページへ。

画面の置きかた：ふつうの向きか、縦置きか

BATRIDER は縦画面のゲームです。OPTIONS の GENERAL SCREEN にある ROTATION（ページ）で、画面の置きかたをゲームに知らせます。

ROTATION画面の置きかた表示
OFFふつうの向き中央に表示し、左右にガジェット（ページ）。最初の設定です。
LEFT縦置き。画面の上端が左にくる回して長い辺いっぱいに表示し、上下にガジェット。
RIGHT縦置き。画面の上端が右にくる逆向きに回します。
注意

すべてのテレビが、縦置きできるように作られているわけではありません。回転に対応した画面やスタンドを使い、通気口は絶対にふさがないでください。また、電源を入れたまま回さないでください。

TEAM EDIT と SELECT PLAYER では、すべての機体が2段に並んで表示されます。上の段はバトライダーの9機、下の段は RAIZING の過去のシューティングゲームから参戦した9機のゲスト機体です。左右で同じ段の中を移動し、上下で段を切り替えます。

チーム

チームは3機で1組です。出撃するのは1機ずつ、順番どおりです。1機が撃墜されると次の機体に交代し、3機目が撃墜されるとプレイは終わります（オリジナルゲームでは、DIP スイッチで1機から4機に変えられます。ページ）。

基本のあそびかた

ステージは画面の上へ向かって進みます。現れる敵を撃ち、敵が落としたものを拾い、機体を残してボスにたどり着きましょう。

初期設定

画面の下にいるのが自機です。チームの機体は交代で出撃します。画面左上のチームのアイコンで、出撃中の機体と待機中の機体がわかります。

ザコ敵は数発で倒せます。大型の敵や、建物の間にある地上の目標は、より多く撃ち込む必要がありますが、そのぶん多くのものを落とします。

勲章

勲章は、取るたびに次の勲章の得点が上がります。段階は全部で19あります。

ランク

ショットを撃つ、アイテムを取る、生き残り続けるといったことでランクが上がり、ランクが高いほどゲームは難しくなります。機体を失うと、ランクは下がります。オリジナルゲームでは、ランクに制限はありません。CHASE! では、ランクは 50% から始まり、75% を超えることはありません。

ボス

どのステージも最後にボスが待っていて、どのボスにも制限時間があります。CHASE! では、その残り時間を画面の上部に秒単位で表示します。時間切れになると、ボスを倒していてもいなくても、戦いは終わります。

当たり判定

赤い輪に囲まれた白い円が、自機のなかで敵弾に当たる唯一の部分です。自機のそれ以外の部分は、敵弾と重なってもかまいません。当たり判定は自機と同じ高さに描かれるため、ゲームが自機の上に描くものには、一緒に隠れます。

当たり判定は、どちらのゲームのすべてのプレイで表示されます。TRAINING のページと、OPTIONS の DEBUG MENU にある HITBOX で、表示を OFF、PLAYER（自機の円。最初の設定）、ALL から選べます。

ALL にすると、アーケード基板自身が判定に使っている枠を、そのとおりに表示します。

  • 赤：触れるとミスになる敵
  • 青：地上物など、撃つことしかできない目標
  • マゼンタ：敵弾
  • そして PLAYER と同じ、自機の白い円
CHASE! モード

CHASE! のルール

CHASE! で変わることのすべてを、1ページにまとめました。このあとのページで、1つずつくわしく説明します。

ランク

50% から始まり、最大でも 75% までしか上がりません。機体を失うと下がりますが、50% より下にはなりません。倍率が高いほど、速く上がります。

チェーン

敵を1体倒すごとに1増えます。16体倒すごとに倍率が1段階上がり、x8 まで上がります。倒した敵の得点には、倍率が掛かります。

タイマー

1.5秒。敵を倒すたびに回復します。画面の上半分にいる間は満タンまで、下半分では1秒まで回復します。

タイマー切れ

x1 より上のとき：倍率が2段階下がります。x1 のとき：チェーンブレイク（チェーンが途切れます）。

撃墜される（ミス）

倍率と勲章の段階が半分になり、タイマーは3秒間止まります。

ボム

ボムの発動中と、その後1秒間、タイマーが止まります。

勲章

近くにあると、自機に引き寄せられます。SHOT を押している間は、どこにあっても引き寄せられます。10段階目以上で勲章を落とすと、チェーンが途切れます。

チェイスブレイク

x4 以上で SPECIAL：敵弾とザコ敵がすべて勲章に変わります。倍率は x1 に戻り、5秒間クールダウンします。

エクステンド

1,000,000点ごとに、撃墜された機体が1機復帰します。残機は最大5です。

敵の狙い

撃ってくる敵の近くを飛んでいると、自機を狙う弾の狙いが甘くなります。

ランクは 50% から 75% の間

CHASE! の新しいプレイは、ランク 50% から始まります。そこからは、ゲームがいつもどおりにランクを上げていきます。毎フレーム少しずつ上がり、ショット、アイテム、エクステンドでさらに上がります。CHASE! ではそれに加えて、x1 より上に保っている倍率の1段階ごとに、独自の上乗せがあります。75% に達すると、そこで止まります。CHASE! のプレイが、それ以上難しくなる瞬間はありません。

機体を失うと、ランクは 50% に向かって下がりますが、50% より下にはなりません。コンティニューすると、ちょうど 50% に戻ります。

CHASE! の基板設定

CHASE! はつねに、基板の難易度 HARD、機体3機の設定を使い、オリジナルゲームのボーナス機体の代わりに独自のエクステンドを使います。DIP スイッチの影響は受けず、TRAINING コースのオートボムもありません。1人用のゲームです。

CHASE! モード

チェーンと倍率

倒して、倒し続けましょう。チェーンは敵を倒した数、倍率はその価値です。

敵を1体倒すごとに、チェーンが1増えます。16体ごとに倍率が1段階上がり、x1 から x8 まで上がります。倒したものの得点はすべて、本来の得点に倍率を掛けた値になります。チェーンは x8 を超えても数え続けられますが、倍率は x8 で止まります。

タイマー

敵を倒すと、チェーンのタイマー（左のレールにあるゲージ）も回復します。

自機の位置敵を倒したときのタイマー
前方（FORWARD）― 画面の上半分1.5秒（満タン）まで回復
後方（BACK）― 画面の下半分1秒まで回復

どちらにいるかは、レールの前方マークでわかります。画面の上へ出ていけば、チェーンは保ちやすくなります。後ろに下がっていると、敵と敵の間に空けられる時間が、毎回0.5秒短くなります。

ヒント

ボス戦では、ボスへの命中もチェーンに数えられ、ボスの攻撃の合間もタイマーを保ってくれます。ボス戦は、倍率を上げる絶好の場面です。

タイマーが切れると

x1 より上のときは、倍率が2段階下がり、タイマーは1秒にセットされます。その1秒の間に何も倒せないと、さらに2段階下がります。

x1 のときは、チェーンが途切れ（チェーンブレイク）、カウントは0に戻ります。

x8 から1体も倒さなかった場合、満タンのタイマーからチェーンブレイクまでは 4.5 秒です。

そのほかチェーンに影響するもの

撃墜される（ミス）倍率が半分になり（x8 は x4 に）、勲章の段階も一緒に半分になります。次の機体が登場するまでの3秒間、タイマーは止まります。
ボムボムの発動中と、その後1秒間、タイマーが止まります。その間に倒した敵も、チェーンに数えられます。
勲章を落とす勲章の段階が10段階目（1,000）以上のときに勲章を画面の外へ落とすと、チェーンが途切れます。
チェイスブレイク自分で倍率を使い、x1 に戻ります（ページ）。
コンティニューチェーン、倍率、勲章の段階が最初からになります。
CHASE! モード

勲章とマグネット

勲章の段階は、オリジナルゲームのものです。CHASE! が加えるのは、マグネットです。

自機からおよそ100ピクセル（画面の幅の約5分の2）以内に入った勲章は、自機へまっすぐ引き寄せられます。

SHOT を押し続けると、マグネットは画面全体に届き、画面上のすべての勲章が自機に飛んできます。

地上で止まっている勲章（ボムで建物から飛び出すもの）は、ボタンを押していてもいなくても、どこからでも引き寄せられます。

マグネットが働くのは、自機が飛んでいる間です。1機が撃墜されてから次の機体が登場するまでの間は、勲章はこれまでどおりに落ちていきます。

ヒント

マグネットのおかげで、勲章の段階はずっと安全に上げられます。そして、段階には二重に守る価値があります。10段階目以上で勲章を落とすと、勲章の段階とチェーンの両方を失うからです。

CHASE! モード

チェイスブレイク

倍率と引き換えに、画面いっぱいの勲章を手に入れましょう。

倍率が x4 以上のときに SPECIAL（X）を押すと、チェイスブレイクが発動します。倍率と引き換えに、次のことが起こります。

  • 画面上の敵弾がすべて消え、ザコ敵がすべて破壊されます。それぞれの得点も入ります。
  • そのひとつひとつが、現在の段階と同じ得点の勲章を残し、マグネットがそれを自機まで運びます。画面にそれ以上勲章を出せないときは、残りの分が同じ得点でスコアに直接加算されます。
  • 倍率は x1 に、チェーンは0に戻ります。

その後、倍率は5秒間クールダウンします（倍率は x1 のまま）。その間も敵を倒せば得点は入りますが、チェーンは増えません。レールのゲージには、クールダウンの残りが白で表示されます。倍率をもう一度 x4 まで上げるまで、次のチェイスブレイクはできません。

画面では短い名前で表示されます。発動すると、ステージ表示の行に CASH IN と点滅します。

ボスはザコ敵ではありません。ボスだけがいて敵弾もないときなど、画面に勲章へ変えられるものが何もない場合は、ボタンを押しても何も起こらず、倍率はそのままです。

ヒント

チェイスブレイクで出た勲章はボーナスであって、リスクではありません。取り逃がしてしまっても、勲章の段階はリセットされません。

メモ

SPECIAL は、オプションのフォーメーションを切り替えるボタンでもあります。ほとんどの機体では、この2つがぶつかることはありません。一部のゲスト機体は、SPECIAL でフォーメーションが切り替わります。これらの機体では、短く押す（0.5秒以内に離す）と、離したときにフォーメーションが切り替わり、長く押す（0.5秒間押し続ける）とチェイスブレイクになって、フォーメーションは変わりません。

CHASE! モード

残機・エクステンド・コンティニュー

エクステンド

1,000,000点ごとにエクステンドを獲得し、ステージ表示の行に EXTEND が点滅表示されます。

エクステンドすると、撃墜された機体が1機復帰し、チームの最後尾に加わります。撃墜された機体がないときは、エクステンドはストックされ、次に機体が撃墜されたときにすぐ使われます。

残機は、残っている機体とストック中のエクステンドを合わせて、最大5までです。残機が5のときに獲得したエクステンドは、代わりに 100,000点になり、行には MAX LIVES が点滅表示されます。

チームのアイコンの横の数字が、残機の数です。残り1になると赤くなります。

コンティニュー

最後の機体が撃墜されると、CONTINUE? と表示され、カウントダウンが始まります。START を押すと、同じチームでプレイを続けられます。

コンティニューは、PLAY の CONTINUES で5回または7回に設定していないかぎり、1回のプレイにつき3回です。コンティニューすると、チェーン、倍率、勲章の段階が最初からになり、ランクは 50% に戻ります。

コンティニューすると、そのプレイのスコアは無効になります（ページ）。TRAINING にはコンティニューがなく、GAME OVER になると TRAINING のページに戻ります。

オリジナルゲーム

PLAY の MODE を ORIGINAL にすると、START RUN は、アーケード基板そのままの ARMED POLICE BATRIDER になります。

CHASE! のルールは、いっさい適用されません。チェーンも、マグネットも、チェイスブレイクもなく、ランクにも制限はありません。アーケード基板の工場出荷時の設定（難易度 NORMAL、機体3機、1,500,000点ごとにエクステンドのアイテム）でプレイしますが、DIP スイッチで変えることもできます（ページ）。フリープレイで、画面もゲーム本来のものです。CHASE タグはありませんが、当たり判定は表示されます。横に並ぶガジェットは、どちらのゲームでも働きます（ページ）。

2つのゲームに共通しているのは、プレイのまわりにあるものすべてです。メニュー、ポーズメニュー、PLAY で設定するコンティニュー回数、TRAINING、ステートセーブとリプレイ、1人用であることです。ランキングは、それぞれ別々です。

ステートセーブ

いまのゲームの状態をそのまま残して、好きなときにその場面へ戻れます。

SAVE STATE（ポーズメニュー）と LOAD STATE（ポーズメニューとタイトルメニュー）を選ぶと、スロットのページが開きます。スロットは MODE ごとに10個（CHASE! と ORIGINAL）あり、それぞれにセーブしたときのステージとスコアが、選んでいるスロットにはそのときのゲーム画面の小さな写真が表示されます。

SAVE STATE

プレイ中に使えます。スロットを選んで A を押すと、そこにセーブされます。使用中のスロットは、確認のあと上書きされます。

LOAD STATE

左右で、もう一方の MODE のスロットに切り替わります。A で確認のあと読み込みます。もう一方の MODE のステートを読み込むと、ゲームもその MODE に切り替わります。X でステートを消去します（確認があります）。

読み込んだあと、ゲームはポーズメニューで待っています。RESUME を選ぶと再開します。読み込むと、そのプレイのスコアは無効になり、リプレイの記録も終わります（ページ）。

メモ

ランキングは、つねにいまセーブされている内容のままです。古いステートを読み込んでも、古いランキングが戻ってくることはありません。

ステートは、.xex と同じ場所のファイルにセーブされます。CHASE! は batrider360_state_c01.bin～_c10.bin、ORIGINAL は _o01.bin～_o10.bin です。batrider360 のほかのバージョンでセーブしたステートは、読み込めないことがあります。

リプレイ

プレイはすべて、最初から記録されています。よいプレイは残しておきましょう。

プレイが終わると SAVE REPLAY? と表示され、MODE、到達したステージ、スコア、プレイ時間が出ます。A で残し、B で残しません。10秒に満たないプレイと、リプレイを残せないプレイ（ページ）では表示されません。リプレイは30個まで残せ、いっぱいのときは、いちばん古いものと置き換わります。

REPLAY DATA

タイトルメニューの REPLAY DATA を選ぶと、残したリプレイが新しい順に12個ずつ並び、上に30個のうちいくつ使っているかが出ます。それぞれに MODE（CHA か ORG）、到達したステージ、スコア、長さが表示され、無効なスコアの行は赤く * がつきます。A で再生、X で消去します（確認があります）。

ガジェット

縦画面のゲームをワイドテレビに映すと、左右に広い余白ができます。Xbox 360版はそこを、動いているゲームを読み取るパネルで埋めます。

ガジェットは、アーケード基板がメモリーに持っていながら画面には出さないもの――ランク、これから出るアイテム、隠しボスの条件など――を見せてくれます。Baffo 氏による MAME 用 Batrider レイアウト（バージョン 0.4：デザイン baf、Lua Olifante & DUBS、ランク開始バー Miquel）を移植したもので、CHASE! 用の新しいパネルを同じスタイルで加えています。OPTIONS の GADGETS でオフにできます。4:3 の画面と、PICTURE SIZE が CUSTOM のときも表示されません。

ゲームの左側

CURRENT PLAYER3機の顔（先頭が出撃中、続く2機が待機中）と、チームのタイプ（A～D）。横に入力表示（押しているスティックとボタン）と、ショットのチャージ。
STATUSステージ、そのステージの経過時間、画面上の敵の数と敵弾の数。
WEAPONショットのレベル、オプションの数、そのフォーメーション（フォーメーションがあるのはバトルガレッガのゲスト機だけ：V、BACK、FRONT、CIRCLE、CONTROL、特殊フォーメーションは SPECIAL）、ボムのストック、Sp.Power と Sp.Option のマーク。
MUSICいま流れている曲。ゲーム自身のサウンドテストの曲名と、その作曲者。

CHASE! のパネル（下側）

CHAINチェーンのタイマーのバーと、その下にチェーンの数（ページ）。
MULTIPLIER倍率 x1～x8。チェイスブレイクが使えるときはオレンジ色の C、そして前方の矢印（画面の上半分では上向き、下半分では下向き）。
LIVES残っている機体とストック中のエクステンド。最大5。
NEXT EXTEND次のエクステンドまでの残りの点数。

ゲームの右側

RANK BARランク（％）と、ランク開始値（このプレイのランクがどこから始まったか）。
ITEM DROPSアイテムの出る順番の、次の6個（ページ）。
ITEM COUNT種類ごとに、これまで出たアイテムの数。上限に達すると赤くなります。
MEDALこれまで出た勲章の数と、次の勲章（その絵と得点）。
SECRET BOSSES隠しボスを呼び出す12の条件。まだ可能性があるものは空欄、満たしたものはチェック、失ったものはマイナスで示します。
BOSS INFOボスの耐久力と、タイマー（秒）。
STAGESステージごとに、プレイした順に稼いだ点数と、その合計（TOTAL）。スコアが無効なときは赤くなります（ページ）。

オリジナルゲームと縦置き

オリジナルゲームのプレイにはチェーンがないので、CHASE! のパネルの場所は空いたままです。ほかのパネルは、CHASE! と同じように働きます。

縦置き（ROTATION LEFT か RIGHT）では、ガジェットはゲームの上下の帯に並びます。Secret Bosses と Stages は、ふつうの向きの画面だけで表示されます。

セーブについて

アーケード基板は、電源を切るとすべてを忘れてしまいます。このバージョンは忘れません。

すべて、batrider360.xex と同じ場所にある、名前が batrider360_ で始まる小さなファイルにセーブされます。操作は何もいりません。変更のあった部分を、ゲームを止めることなく、裏で書き込みます。

セーブされる内容タイミング
画面とサウンドの設定、GADGETS、LANGUAGE、HITBOX、MODE（batrider360_host.txt）何かを変更してページやメニューを閉じたとき
CONTINUES、CONTROLS、SECRET COMMANDS、DIP スイッチ、サウンドテストの番号（batrider360_options.txt）同上
MODE ごとのランキング：各テーブルの上位5位まで（batrider360_rankings_chase.bin、_original.bin）内容が変わったとき
ステートセーブ（batrider360_state_c01～_c10、_o01～_o10）：MODE ごとに10個セーブしたとき、消去したとき（ページ）
リプレイ（batrider360_replay_01～_30）：最大30個残したとき、消去したとき（ページ）
メニューの効果音（batrider360_menusnd.bin）。ROM セットから作ります最初の起動時

TRAINING のページの設定は、本体の電源を切るまで（とステートセーブの中に）残ります。ログ batrider360.log は、起動するたびに書き込まれます。

メモ

ファイルはゲームと一緒に持ち運べます。フォルダごとコピーすれば、スコアと設定もついてきます。ファイルを消すと、最初の状態から始まります。フォルダは、本体が書き込めるドライブに置いてください。

.xex の横には、ゲームが書き込むのではないファイルが1つあります。MANUAL のページで読む取扱説明書、batrider360_manual.bin です。配布ファイルの中で batrider360.xex と並んでいるので、2つは一緒に置いておいてください。

スコアがセーブされるタイミング

スコアがセーブ対象のランキングに入るのは、ネームエントリーが終わったときです。スコアが伸びている途中では入りません。ネームエントリーの途中でゲームを終えたり電源を切ったりすると、そのプレイのスコアは失われます。

ランキングは MODE ごとに別々で、コースごとにテーブルが1つあります。CHASE! のスコアとオリジナルゲームのスコアが混ざることはありません。どのプレイが登録されるかは、ページを見てください。

最初からやり直すには

DEBUG MENU の INITIALIZE RANKINGS で1つまたは両方の MODE のランキングを、DEFAULT SETTINGS ですべてのオプションを、それぞれ確認のあと元に戻します（ページ）。

メモ

チェーンを追え。

敵を16体倒すごとに1段階、全8段階。次の敵を見つけるまでの猶予は1.5秒。前に出ればタイマーは味方。下がれば、そうはいかない。勲章は向こうから飛んでくる。そして画面が敵弾で埋めつくされたら、ボタンひとつで、その1発1発がすべて黄金に変わる。

CHASE! と、1998年のオリジナルアーケードゲーム。ランキングは、それぞれ別々に。すべてのステージとボスを練習できるトレーニング、ステートセーブとリプレイ。そしてゲームの横には、基板のすべてを映すガジェット。
